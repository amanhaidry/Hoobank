# Hoobank - (Landing Page)

Hoobank is a modern banking application designed to improve frontend development, UI/UX design, and responsiveness skills. This project is built using **React** and **Tailwind CSS**, focusing on creating a sleek, responsive, and user-friendly interface. Additionally, it supports **Progressive Web App (PWA)** functionality, making it installable and usable offline.

## Purpose of the Project

This project is aimed at:

- Enhancing **frontend development skills**.
- Practicing **responsive design** techniques for various screen sizes.
- Improving **UI/UX design** skills by creating a modern and intuitive interface.
- Learning and implementing **PWA features** for offline support and app-like behavior.

## Features

- **Modern UI/UX**: A clean and responsive design for an enhanced user experience.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop devices.
- **PWA Support**: Installable on devices and usable offline.
- **Tailwind CSS**: Utility-first CSS framework for rapid styling.
- **React**: Component-based architecture for building reusable UI components.

## Technologies Used

- **React**: For building the user interface.
- **Tailwind CSS**: For styling and responsiveness.
- **vite-plugin-pwa**: To enable PWA functionality.
- **Vite**: For fast development and build processes.

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/amanhaidry/Hoobank.git
   ```
2. Navigate to the project directory:
    ```bash
    cd hoobank
    ```

3. Install dependencies:
    ```bash
    npm install
    ```

4. Start the development server:
    ```bash
    npm run dev
    ```

5. Open your browser and go to `http://localhost:5173` to view the application.
